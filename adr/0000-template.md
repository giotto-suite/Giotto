## Context

The forces in play: the constraint, the measurement, the upstream limitation,
the scale target. Enough that someone who disagrees with the decision can see
what they would have to argue with. Write it so it stays true — this section
describes the situation *then*, and does not get updated as the code moves.

## Decision

## Consequences

future code, and the conditions under which it should be revisited.
